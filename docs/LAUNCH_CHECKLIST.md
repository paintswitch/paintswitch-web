# PaintSwitch launch checklist

Last updated: 2026-08-04

This checklist organizes the remaining work needed for PaintSwitch releases. It does not approve **Proposed** or **TBD** product decisions. D-018 makes the lead-generation beta first; D-029 through D-032 confirm the owner-notification destination, technical safeguards, internal sender, and publication of the exact workflow. One controlled website-to-GoHighLevel Preview success path is verified, but it does not waive triggered-message inbox receipt, failure/retry/concurrency testing, rate-threshold testing, authentication, production delivery, legal/privacy, hosting, human-response, or launch-acceptance gates.

## Lead-generation beta readiness snapshot

The earlier **49%** estimate is retired because it predates the private integration, seven-field configuration, server-only Vercel setup, delivery implementation, and branch Preview. A replacement percentage has not been approved or mechanically established. A controlled access-protected Preview test must not be counted as live production or launch acceptance.

Current verified progress includes one access-protected Preview browser submission with all seven fields, exact on-page success, matching GoHighLevel Contact/Opportunity values, persisted source/campaign attribution, exactly one finished workflow enrollment and successful internal-notification action, one completed Upstash state containing provider IDs, payload hash, completion phase, version, and updated timestamp but no raw submitted intake fields with a near-30-day TTL/no lock, and one Preview rate-key increment. The Preview environment setting and latest branch Preview were restored to `false`, Production remained `false`, and the enabled immutable URL remains protected. Current blockers include production promotion/E2E, triggered-message inbox receipt and failure recovery, retry/concurrency and hosted rate-threshold testing, branded-domain authentication, Privacy/Terms and consent, broader data policy, compliant hosting, owner response rehearsal, and final launch QA. The live site remains the prior build.
